# Abiline

Isiklik abiline: päevaplaan, toit ja makrod, kaal, kalender, eesmärgid ja visioonitahvel.
Installitav veebiäpp (PWA), töötab ka ilma netita. Andmed on salvestatud ainult sellesse seadmesse, kus neid sisestad.

## Üles panemine GitHub Pagesi

1. Tee GitHubis uus repo (nt `abiline`) ja lae kõik selle kausta failid sinna üles.
2. Repo Settings → Pages → Source: "Deploy from a branch", haru `main`, kaust `/ (root)`.
3. Minuti pärast on äpp aadressil `https://KASUTAJANIMI.github.io/abiline/`.
4. Ava link telefonis ja vali "Lisa avaekraanile".

## Uuendamine

Pärast failide muutmist tõsta `sw.js` failis `CACHE` versiooninumbrit (nt `abiline-v2`), et telefon võtaks uue versiooni.
